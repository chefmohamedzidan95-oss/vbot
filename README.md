# 🍿 أفلام و مسلسلات FlixMix Telegram Bot

بوت تيليجرام متطور للأفلام والمسلسلات مع دعم التصفح بالتصنيفات، نتائج بحث في أزرار مع صفحات (Pagination)، ومشاهدة مباشرة عبر زر **WebApp**.

## ✨ المميزات الرئيسية

1. 🍿 **اسم البوت والهوية**: أفلام و مسلسلات FlixMix 🍿
2. 📄 **نتائج بحث منظمة (10 نتائج لكل صفحة)**:
   - عرض النتائج داخل رسالة واحدة بأزرار شفافة (Inline Keyboard).
   - أزرار للتنقل بين الصفحات (`◀️ السابقة` و `التالية ▶️`).
3. 🌐 **نظام مصادر ومواقع قابل للتطوير (Multi-Source Providers System)**:
   - بنية برمجية موديولار (`BaseProvider` & `ProviderManager`).
   - إمكانية إضافة أي موقع جديد أو مصدر أفلام/مسلسلات بسهولة عبر إنشاء فئة جديدة في مجلد `providers/`.
   - إمكانية التبديل بين المصادر الحالية بنقرة زر من داخل البوت.
4. 📱 **مشاهدة عبر زر WebApp**:
   - زر `🍿 مشاهدة الآن (Web App)` يفتح المشغل مباشرة داخل التليجرام.
   - إزالة روابط الموقع المباشرة النصية لحماية واجهة البوت وتسهيل تجربة المستخدم.
5. 📂 **التصنيفات والأنواع الخاصة بكل مصدر**:
   - قائمة تصنيفات مخصصة لكل مصدر (أفلام أجنبية، عربية، أكشن، مسلسلات تركية، كورية، إلخ).
   - تصفح نتائج التصنيفات مع نظام الصفحات (10 نتائج/صفحة).

## 🛠️ كيفية إضافة موقع/مصدر جديد مستقبلاً

لإضافة مصدر جديد للأفلام والمسلسلات:
1. أنشئ ملفاً جديداً داخل مجلد `providers/` وليكن `my_source.py`.
2. ورّث من الفئة `BaseProvider` وطبّق الدوال التالية:
   - `search(query, page)`
   - `get_by_category(category_id, page)`
   - `get_video_details(vid, extra)`
   - `get_series_episodes(series_identifier)`
   - `get_categories()`
   - `get_web_app_url(video)`
3. قم بتسجيل المصدر في `providers/manager.py`:
   ```python
   from .my_source import MySourceProvider
   self.register_provider(MySourceProvider(config_path=config_path))
   ```

## 🚀 التثبيت والتشغيل

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. ضبط التوكن:
افتح `config.json` وأضف توكن البوت الخاص بك في حقل `telegram_token`.

### 3. تشغيل البوت:
```bash
python bot.py
```
